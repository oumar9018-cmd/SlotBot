# SlotBot — Weekly Tutor Settlement Tracker

**Rule:** every Monday, settle last week's paid bookings per tutor via UPI/bank.
No settlement older than 7 days. Screenshot of transfer → send to tutor on Telegram.

## How to get the numbers

Tutor's dashboard shows total Stars earned. For weekly settlement:
1. Ask tutor for UPI ID (collect during setup call — write it below).
2. Monday: check dashboard earnings, subtract already-settled amount.
3. Transfer INR equivalent, note the Stars→INR rate you used that week.
4. Mark settled + date. Send tutor the screenshot.
